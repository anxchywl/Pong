# Pong

A small 2D Pong game made with Unity. The project is intentionally simple and open for experimentation, learning, and contributions.

## Getting started

You’ll need [Unity Hub](https://unity.com/download) and Unity `6000.5.3f1`.

1. Clone this repository.
2. Add the project folder in Unity Hub and open it with the required editor version.
3. Open `Assets/Main.unity` and press **Play**.

## Project layout

- `Assets/` — scenes, scripts, art, and settings
- `Packages/` — Unity package manifest and lock file
- `ProjectSettings/` — project configuration
- `.github/` — CI and contribution templates

Generated Unity folders such as `Library`, `Temp`, `Logs`, and `UserSettings` are intentionally excluded from Git.

## Contributing

Bug reports, ideas, and pull requests are welcome. For changes, please explain what you changed, how you tested it in Unity, and keep generated files out of commits. Pull requests are checked by GitHub Actions when the repository has a `UNITY_LICENSE` secret configured.
